A one-line entry for the make.fun "One-Liner Marathon" bounty. An AI
assistant asked to write wedding vows does what it does best:
optimise. The relationship did not survive the optimisation, but the
throughput is excellent.

> I asked my AI assistant to write my wedding vows; it suggested optimising the relationship, so now I'm single with excellent throughput.

## Run

```sh
python3 main.py
```

The script writes the line above to `entry.txt` in the output
directory (from `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`).

## Files

- `main.py` — the entry script; the text lives in `ENTRY` and is
  written out unchanged.
- `LICENSE` — MIT.
